2. Technical Foundation

A. Next.js 15 — The Frontend Framework

The Piyumverse is built on Next.js 15, the industry-standard React framework for production-grade web applications.

FeatureHow It Powers the System
App RouterFile-system based routing where folders define routes. Pages like /about, /projects, and /philosophy are simply folders in the codebase.
Server ComponentsPages render on the server, delivering faster load times, better SEO, and less JavaScript sent to the browser.
Server ActionsReplace traditional API routes for form submissions and data mutations. The contact form sends messages directly to the database without writing a separate API.
TurbopackFaster builds and hot-reloads during development.
Why Next.js: SEO-first (Google crawls every page instantly), performance-optimized even on mobile networks in Sri Lanka, and scales effortlessly as features grow.

B. Payload CMS 3 — The Backbone

Payload is the first-ever Next.js native CMS. It installs directly into the /app folder and runs in the same Node process as the Next.js application.

FeatureWhat It Means
Code-FirstDatabase schema, admin interface, and API are all defined through TypeScript configurations. No clicking around a UI to build data models.
Full TypeScript BackendAuto-generated REST and GraphQL APIs with complete type safety.
Admin PanelPowerful, customizable dashboard for managing all content.
Self-HostedDeploy to Vercel, Railway, or any platform. No third-party CMS controls the data.
Free & Open SourceMIT licensed — full ownership of the entire system.
Why Payload: Zero vendor lock-in (move anywhere, anytime), complete control over every field and relationship, and a single codebase for CMS and website.

Data Flow

  1. Visitor requests a page (e.g., /projects/aegisvue)
  2. Next.js Server Component fetches data from Payload's Local API
  3. Payload queries the PostgreSQL database
  4. Data is returned as typed JSON and rendered into HTML on the server
  5. HTML is sent to the browser — fully indexed by search engines

5. Advanced Features & Plugins

A. AegisVue Butler — AI Agent Plugin

The payload-ai-agent plugin adds a floating chat assistant to the admin panel that turns natural-language commands into real panel actions. Branded as "AegisVue Butler" — Piyum's custom J.A.R.V.I.S. for website management.

Command TypeExample
Bulk Updates"Set all project statuses to 'Production'"
Content Search"Find all projects with the tag 'AI'"
Content Creation"Create a new project called 'AegisVue' with description..."
Content Editing"Rewrite this project description in a professional tone"
Data Queries"List all projects that have '1st Runner-Up' in achievements"
How it works: Uses LLM tool calling on top of the Payload Local API. Every action runs with the exact permissions of the signed-in user. Bring your own AI provider (OpenAI, Anthropic, Google, Groq, Ollama).
